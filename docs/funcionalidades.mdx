# Funcionalidades

## Implementadas

- Cadastro de usuário com validação de campos
- Cadastro em etapas com seleção de nacionalidade carregada do banco de dados
- Login com autenticação JWT
- Rotas protegidas — redirecionamento automático para login sem token
- Responsividade para desktop e mobile, a partir de 320px
- Lista de nacionalidades servida pelo banco de dados
- Menu lateral no desktop e navbar inferior no mobile
- Documentação da API em `/docs` (Swagger UI)

- Feed de publicações paginado
- Publicação de blabs, com seletor de emojis completo e busca
- Curtidas, comentários e respostas ao próprio conteúdo
- Exclusão de publicações e comentários pelo autor
- Edição de comentários nos primeiros quinze minutos
- Busca de publicações e de usuários, em abas separadas
- Perfil editável, com foto, bio e dados pessoais
- Tema claro e escuro, acompanhando a preferência do sistema
- Edição de publicações dentro da janela de quinze minutos
- Página dedicada da publicação, com autor e comentários
- Seção de publicações no perfil, próprio e de terceiros

- Perfil público sem dados pessoais — e-mail, nascimento e nacionalidade só no próprio perfil
- Sistema de seguidores, com marcação de "segue você"
- Política de privacidade em página própria, com aceite obrigatório no cadastro
- Confirmação de e-mail por código de seis dígitos, exigida antes do primeiro login
- Redefinição de senha por código enviado ao e-mail
- Exclusão de conta em três etapas, confirmada por código

## Em desenvolvimento

- Respostas a comentários com menção ao autor
- Chat em tempo real via WebSockets
- Notificações em tempo real
- Status de entrega de mensagens
