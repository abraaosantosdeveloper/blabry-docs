# Funcionalidades

## Implementadas

- Cadastro de usuário com validação de campos
- Cadastro em etapas com seleção de nacionalidade carregada do banco de dados
- Login com autenticação JWT
- Rotas protegidas — redirecionamento automático para login sem token
- Responsividade para desktop e mobile, a partir de 320px
- Lista de nacionalidades servida pelo banco de dados
- Menu lateral no desktop e navbar inferior no mobile
- Documentação da API em `/docs` (Swagger UI)

## Em desenvolvimento

- Feed de publicações paginado
- Publicação de blabs, com seletor de emojis
- Curtidas e comentários
- Busca de usuários paginada
- Foto de perfil com recorte e envio ao Cloudinary
- Bio no perfil
- Chat em tempo real via WebSockets
- Notificações em tempo real
- Status de entrega de mensagens
