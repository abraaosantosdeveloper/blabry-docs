## Deploy

| Serviço | Finalidade |
|---|---|
| GitHub Pages | Hospedagem do frontend e da documentação |
| Railway | Hospedagem da API e do banco de dados |
| Cloudinary | Armazenamento das fotos de perfil |
| Resend | Entrega dos e-mails de código de verificação |
| Registro.br | Domínio `blabry.com.br`, usado como remetente autenticado |
| gh-pages | Automação do deploy |

O domínio existe por causa do e-mail, e não do site. Um remetente em domínio
de terceiros não pode publicar SPF e DKIM próprios, e sem eles a mensagem
chega marcada como não autenticada — quando chega. `blabry.com.br` foi
registrado e delegado ao Resend por três registros DNS: o CNAME de DKIM, o
de retorno (*bounce*) e o de rastreio.
